THỰC HÀNH
THIẾT KẾ VÀ TRIỂN KHAI HỆ THỐNG MULTI-AGENT TƯ VẤN SẢN PHẨM
1. Mục tiêu: Thiết kế một hệ thống AI gồm nhiều Agent chuyên trách phối hợp để phân tích yêu cầu, truy xuất dữ liệu, suy luận, đưa ra khuyến nghị, kiểm chứng kết quả và sinh phản hồi cuối cùng.
2. Yêu cầu bắt buộc:
Xây dựng tối thiểu 6 Agent; 
Có 1 Orchestrator Agent; 
Có cơ chế trao đổi message có cấu trúc; 
Có ít nhất 2 loại Tool: SQL Tool, Vector Search Tool 
Có MySQL Database; 
Có Knowledge Base/Vector Database; 
Có Critic Agent; 
Có cơ chế retry khi kết quả bị từ chối; 
Có giao diện Web; 
Có logging toàn bộ quá trình phối hợp; 
Có tối thiểu 10 test cases; 
So sánh hệ thống Multi-Agent với hệ thống Single-Agent về độ chính xác, thời gian đáp ứng và số lần gọi LLM.
3. Sản phẩm

4. Kiến trúc triển khai bài thực hành
Agent 1 — Orchestrator Agent: 
Nhiệm vụ
Orchestrator chịu trách nhiệm:
nhận yêu cầu; 
tạo workflow; 
phân công Agent; 
truyền message; 
theo dõi trạng thái; 
xử lý lỗi; 
retry; 
quyết định khi nào hoàn thành.
Agent 2 — Analyst Agent: Hiểu người dùng đang yêu cầu điều gì.
Ví dụ:
User: "Tìm laptop Dell dưới 20 triệu, RAM từ 16GB, bảo hành 24 tháng."
Analyst Agent chuyển thành dữ liệu có cấu trúc:
{
  "intent": "product_search",
  "category": "Laptop",
  "brand": ["Dell"],
  "max_price": 20000000,
  "min_ram": 16,
  "min_warranty": 24
}
Agent 3 — Database Agent
Agent này chuyên làm việc với MySQL. Nó nhận: 
{
  "category": "Laptop",
  "brand": ["Dell"],
  "max_price": 20000000,
  "min_ram": 16
}
Trả kết quả:
{
  "products": [
    {
      "name": "Dell Inspiron 15",
      "price": 18900000,
      "ram": "16GB",
      "warranty": "24 months"
    },
    {
      "name": "Dell Vostro 14",
      "price": 19500000,
      "ram": "16GB",
      "warranty": "24 months"
    }
  ]
}
Agent 4 — RAG Agent: 
Database chỉ chứa dữ liệu có cấu trúc. Nhưng nhiều thông tin không phù hợp để lưu dưới dạng bảng. Ví dụ: Laptop Dell phù hợp với sinh viên CNTT vì...
Những thông tin này có thể đưa vào: Knowledge Base + Vector Database
Ví dụ: RAG Agent thực hiện:
Question →Embedding→Vector Search→Relevant Documents
Agent 5 — Reasoning Agent
Đây là Agent thực hiện suy luận/tổng hợp. Reasoning Agent có nhiệm vụ:
Đối chiếu dữ liệu; 
Loại bỏ sản phẩm không phù hợp; 
So sánh; 
Suy luận; 
Đưa ra recommendation.
Agent 6 — Critic Agent
Đóng vai trò reviewer. Ví dụ Reasoning Agent đưa ra:
Dell Inspiron 15:
19 triệu
RAM 16GB
Bảo hành 24 tháng
Critic kiểm tra:
✓ Giá có đúng MySQL không?
✓ RAM có đúng không?
✓ Warranty có đúng không?
✓ Có thông tin nào hallucination không?
✓ Recommendation có phù hợp không?
Kết quả:
{
  "status": "REJECT",
  "score": 0.72,
  "errors": [
    "Warranty information is not supported by retrieved data"
  ]
}
Agent 7 — Response Agent: Agent cuối cùng chuyển kết quả thành câu trả lời cho người dùng.
Ví dụ dữ liệu:
{
  "recommendation": "Dell Inspiron 15",
  "reason": [
    "Price: 18.9M",
    "RAM: 16GB",
    "Warranty: 24 months"
  ]
}
Response Agent chuyển thành:
Dell Inspiron 15 là lựa chọn phù hợp nhất.
Giá: 18,9 triệu 
RAM: 16GB 
Bảo hành: 24 tháng 
Phù hợp với ngân sách và yêu cầu của bạn.
Phần so sánh Single-Agent với Multi-Agent sẽ biến bài này từ một bài "làm chatbot" thành một bài thực hành có tính chất nghiên cứu và đánh giá kiến trúc Agentic AI. Đây cũng là hướng phù hợp để nối tiếp các nội dung trước về AI-Augmented SDLC, RAG, Tools, MCP và Skills.  Chúng ta có thể dùng chính các Agent để thực hiện từng giai đoạn của SDLC ở một bài thực hành tiếp theo.
5. Các bước thực hiện (Sinh viên có thể sử dụng Agent để thực hiện hoặc làm thủ công theo từng bước)
Multi-Agent Product Advisor – hệ thống gồm nhiều Agent phối hợp để phân tích nhu cầu khách hàng, truy vấn MySQL, sử dụng Knowledge Base/Vector DB, đưa ra khuyến nghị, kiểm tra bằng Critic Agent và retry nếu bị từ chối.

import mysql.connector
import os
from dotenv import load_dotenv
load_dotenv()
def get_connection():
    return mysql.connector.connect(
        host=os.getenv("MYSQL_HOST", "localhost"),
        port=int(os.getenv("MYSQL_PORT", "3306")),
        user=os.getenv("MYSQL_USER", "root"),
        password=os.getenv("MYSQL_PASSWORD", ""),
        database=os.getenv("MYSQL_DATABASE", "multi_agent_shop")
    )
def get_all_products():
    connection = get_connection()
    cursor = connection.cursor(dictionary=True)
    cursor.execute("SELECT * FROM products")
    products = cursor.fetchall()
    cursor.close()
    connection.close()
    return products

Mở: models/agent_message.py
from pydantic import BaseModel
from typing import Any, Optional
class AgentMessage(BaseModel):
    task_id: str
    from_agent: str
    to_agent: str
    message_type: str
    payload: Any
    status: str = "success"
    error: Optional[str] = None
Ví dụ một message:
message = AgentMessage(
    task_id="TASK-001",

PHẦN VI — TẠO BASE AGENT
Bước 15. Tạo base_agent.py
Mở: agents/base_agent.py
from abc import ABC, abstractmethod
class BaseAgent(ABC):
    def __init__(self, name):
        self.name = name
    @abstractmethod
    def process(self, message):
        pass
Mục đích của lớp này là buộc các Agent có cùng một giao diện:
Agent
  │
  ├── process()
  │
  ├── name
  │
  └── message
PHẦN VII — XÂY DỰNG AGENT ĐẦU TIÊN
Bước 16. Tạo Gemini Service
Mở: services/gemini_service.py
import os
from dotenv import load_dotenv
from google import genai
load_dotenv()
client = genai.Client(
    api_key=os.getenv("GEMINI_API_KEY")
)
def generate_text(prompt):
    response = client.models.generate_content(
        model="gemini-3.1-flash-lite",
        contents=prompt
    )
    return response.text
Bước 17. Tạo Requirement Agent
Mở: agents/requirement_agent.py
import json
from agents.base_agent import BaseAgent
from services.gemini_service import generate_text
class RequirementAgent(BaseAgent):
    def __init__(self):
        super().__init__("requirement_agent")
    def process(self, message):
        question = message.payload["question"]
        prompt = f"""
Bạn là Requirement Analysis Agent.
Nhiệm vụ:
Phân tích yêu cầu mua sản phẩm của khách hàng.
Hãy chuyển câu hỏi thành JSON.
Các trường cần xác định:
- category
- brands
- max_price
- min_price
- min_ram
- max_weight
- min_warranty
- use_cases
Nếu không có thông tin thì dùng null.
Chỉ trả về JSON hợp lệ.
Câu hỏi khách hàng:
{question}
"""
        result = generate_text(prompt)
        result = result.strip()
        if result.startswith("```"):
            result = result.replace("```json", "")
            result = result.replace("```", "")
            result = result.strip()
        data = json.loads(result)
        return data
